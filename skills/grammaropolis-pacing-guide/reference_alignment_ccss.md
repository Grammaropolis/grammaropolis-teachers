# Standards alignment: Common Core State Standards (CCSS), Grades 1-8

*Standard identifiers from the Common Core State Standards for English Language Arts. © Copyright 2010 National Governors Association Center for Best Practices and Council of Chief State School Officers. All rights reserved.* Descriptors below are the standards' text, with examples removed and long standards shortened. One descriptor, L.1.1.H, is restated in plain terms.

**Notation.** Codes drop the `CCSS.ELA-LITERACY.` prefix: `L.5.2.A` is Language, Grade 5, standard 2, sub-standard A. A code with no final letter is the parent of the lettered codes under it.

**How to use this file.** Read only the section for the plan's grade. Each section has two parts. The topic table lists every Grammaropolis topic that teaches a code at that grade, the codes its lessons teach directly, and one line per code saying what students do for it. The in-scope list gives every Language standard at that grade, plus any Writing standard a topic teaches, with the topics that teach it, so a plan can report honestly what it covers and what it leaves out. "Partly addressed in" names a topic that touches a standard without teaching all of it; that standard is never cited on a week. Each section starts at its "## Grade N" heading and ends at the next one.

**Hard rule.** Cite a code for a week only if this file lists it for that topic at that grade. Never build a code by pattern, never move a code to another grade, and never cite a code from the in-scope list that no topic teaches.
