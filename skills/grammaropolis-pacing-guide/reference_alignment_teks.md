# Standards alignment: Texas Essential Knowledge and Skills (TEKS), Grades 1-8

*Source: Texas Essential Knowledge and Skills, 19 Tex. Admin. Code Chapter 110, adopted 2017. Descriptors below are short paraphrases for planning, not the rule text.*

**Notation.** `5.11(D)(i)` is Grade 5, knowledge and skills statement (11), student expectation (D), item (i). In Grades 1-5 the editing conventions list is (11)(D); in Grades 6-8 it is (10)(D).

**How to use this file.** Read only the section for the plan's grade. Each section has two parts. The topic table lists every Grammaropolis topic that teaches a code at that grade, the codes its lessons teach directly, and one line per code saying what students do for it. The in-scope list gives every editing conventions expectation at that grade, plus any other expectation a topic teaches, with the topics that teach it, so a plan can report honestly what it covers and what it leaves out. "Partly addressed in" names a topic that touches a standard without teaching all of it; that standard is never cited on a week. Each section starts at its "## Grade N" heading and ends at the next one.

**Hard rule.** Cite a code for a week only if this file lists it for that topic at that grade. Never build a code by pattern, never move a code to another grade, and never cite a code from the in-scope list that no topic teaches.
