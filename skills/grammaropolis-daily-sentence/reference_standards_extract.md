# Standards extract (CCSS only)

The Common Core Language (L) codes each Grammaropolis lesson teaches, for the topics this skill builds, grouped by topic and grade, each with a one-line plain meaning. Codes a lesson touches without teaching in full are listed separately at the end, for tagging only. W.8.3.D is the one Writing code here; every other code is Language. **Cite only codes listed here for the matching topic, and never invent a code from memory.**

All codes are CCSS.ELA-LITERACY with the prefix dropped (`L.4.2.C` means `CCSS.ELA-LITERACY.L.4.2.C`). A code ending in a letter is a sub-standard of the parent code. **Read the plain meaning before citing.** Cite the sub-standard whose meaning matches the day's focus; cite a parent only when no sub-standard at that grade matches, and then say so in the key, because a bare parent code ("capitalization, punctuation, and spelling") tells a teacher almost nothing.

**How to use this file.** One code per day, matched to that day's focus and the class's grade. A mixed-review day, or a focused day with a spiral item, may cite up to three codes, one per error type. If the topic and grade aren't listed, cite the nearest listed grade's code and label it in the key. Citing a lower grade's code: "L.4.2.B (grade 4 standard, reviewed at grade 5)." Citing a higher grade's code: "L.5.2.A (previews the grade 5 standard)." When the class's own grade has a parent code for the area, name it as the grade-level umbrella ("under the grade 5 umbrella, L.5.2"). If the skill a day practices is anchored at a different grade than the class (common versus proper nouns, for example), cite the code that actually matches the skill, at whatever grade it's anchored, and say so plainly rather than force-fitting the class's own grade.

**State standards.** This file is CCSS only. If a teacher gives a state code, keep it visible in the key, and pair it with the closest code below on substance. If you don't know what the state code says, ask the teacher to paste its text. Never guess what a state code means from its format.
