# Standards extract (CCSS)

Two parts. **Part 1** lists the CCSS Language (L) and Writing (W) codes each Grammaropolis lesson teaches, grouped by topic and grade, and ends with codes for tagging items that no lesson teaches in full. **Part 2** paraphrases what each code asks for, so every item can be tagged with the code that actually fits it. Part 2 also paraphrases a few more real CCSS codes for item tagging: L.2.1.A, L.2.1.C, L.4.1.G, L.4.3.B, L.6.1.E, and L.8.5.B.

**How to read this file:** find the topic and grade in Part 1, then read only those codes (and their parents) in Part 2. There's no need to read the whole file for one check.

**All codes are CCSS.ELA-LITERACY, prefix dropped for brevity** (`L.3.1.A` means `CCSS.ELA-LITERACY.L.3.1.A`). A code ending in a letter is a sub-standard of the parent code (`L.3.1.A` sits under `L.3.1`). Citing the parent is always safe; citing the sub-standard is more precise when the item tests exactly what the sub-standard says.

**The rules for citing:**

1. Cite only codes that appear somewhere in this file. Never invent a code or a sub-standard letter, and never cite one from memory.
2. For each item, find the topic and grade in Part 1, then confirm the fit in Part 2. The topic lists show where the catalog is built, and some listed codes cover a topic only broadly. If a listed sub-standard's paraphrase doesn't match what the item tests, cite the parent code or a better-fitting code from Part 2 instead.
3. If the skill is anchored at a different grade than the class (common versus proper nouns is anchored at grade 1, for example), cite the code where the skill is anchored within this file and say so in the key. If the anchor is outside this file (the semicolon and hyphenation rules are named only in high school standards), cite the parent code for the class's grade plus a one-line note saying so.
4. Part 2 is a paraphrase for matching, not a quotation. Never put a paraphrase in quotation marks or present it as the official wording.
5. Non-CCSS state standards are resolved to CCSS first (a crosswalk connector if one is available, otherwise the teacher's pasted text, matched on substance). The teacher's own code stays visible in the key either way.

## Language: conventions of grammar and usage (L.x.1)

Every L.x.1 parent: show command of standard English grammar and usage when writing or speaking.

**Grade 1**
- L.1.1.B: use common, proper, and possessive nouns
- L.1.1.C: use singular and plural nouns with matching verbs in basic sentences (he hops, we hop)
- L.1.1.D: use personal, possessive, and indefinite pronouns (I, me, my; they, them, their; anyone, everything)
- L.1.1.E: use verbs to show past, present, and future
- L.1.1.F: use frequently occurring adjectives
- L.1.1.G: use frequently occurring conjunctions (and, but, or, so, because)
- L.1.1.H: use articles and demonstrative adjectives (pointing words): a, an, the; this, that, these, those
- L.1.1.I: use frequently occurring prepositions (during, beyond, toward)
- L.1.1.J: produce and expand complete simple and compound statements, questions, commands, and exclamations

**Grade 2**
- L.2.1.A: use collective nouns (group, flock)
- L.2.1.B: form and use frequently occurring irregular plural nouns (feet, children, teeth, mice)

- L.2.1.D: form and use the past tense of frequently occurring irregular verbs (sat, hid, told)
- L.2.1.E: use adjectives and adverbs, and choose between them depending on what is being modified
- L.2.1.F: produce, expand, and rearrange complete simple and compound sentences

**Grade 3**
- L.3.1.A: explain what nouns, pronouns, verbs, adjectives, and adverbs do, in general and in particular sentences

- L.3.1.C: use abstract nouns (childhood)
- L.3.1.D: form and use regular and irregular verbs

- L.3.1.H: use coordinating and subordinating conjunctions
- L.3.1.I: produce simple, compound, and complex sentences

**Grade 4**
- L.4.1.A: use relative pronouns (who, whose, whom, which, that) and relative adverbs (where, when, why)

## Writing (W)

Grades 1-2 have parent codes only: W.x.1 (opinion), W.x.2 (informative or explanatory), W.x.3 (narrative), W.x.5 (strengthen writing by revising and editing, with support). A check that asks students to spot the opinion, the reason, the linking word, the order of events, or the closing sentence tags the parent code for its mode.

**Opinion and argument (W.x.1)**
- W.3.1.A, W.4.1.A, W.5.1.A: introduce the topic, state an opinion, and organize the reasons
- W.3.1.B, W.4.1.B, W.5.1.B: give reasons that support the opinion (from grade 4, supported by facts and details)
- W.3.1.C, W.4.1.C, W.5.1.C: use linking words and phrases (because, therefore, for instance, consequently) to connect the opinion and reasons
- W.3.1.D, W.4.1.D, W.5.1.D: give a concluding statement or section
- W.6.1.A, W.7.1.A, W.8.1.A: introduce the claim and organize reasons and evidence (grade 7 adds acknowledging opposing claims; grade 8 adds distinguishing the claim from them)
- W.6.1.B, W.7.1.B, W.8.1.B: support the claim with clear reasons and relevant evidence from credible sources
- W.6.1.C, W.7.1.C, W.8.1.C: use words, phrases, and clauses to clarify how the claim, reasons, and evidence relate
- W.6.1.D, W.7.1.D, W.8.1.D: keep a formal style
- W.6.1.E, W.7.1.E, W.8.1.E: give a concluding statement or section that follows from the argument

**Informative and explanatory (W.x.2)**
