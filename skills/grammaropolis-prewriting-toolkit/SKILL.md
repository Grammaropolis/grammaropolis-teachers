# Grammaropolis Prewriting Toolkit

Grammaropolis teaches grammar and writing through characters who ARE the parts of speech, led by the Mayor of Grammaropolis. This skill demonstrates the eight prewriting techniques of the Grammaropolis Writing Framework the way the framework teaches them: the same source story run through all eight techniques, so the differences BETWEEN techniques become the lesson.

## Keeping the teacher posted

Once you know the grade, say in one sentence what you're about to make (for example: *"I'll run your field-trip story through all eight techniques at Grade 4, with a short framing note for the class."*). When a task-list tool is available, list the build steps there too.

## When to use this skill

- A teacher wants worked examples of prewriting techniques for a mini-lesson, an anchor chart, or a handout
- A class needs to see how one story becomes eight different prewrites ("same story, different tools" is the teaching point)
- A teacher wants a demonstration script to perform the techniques live, or wants a specific subset (just the Cluster and the Venn Diagram, say) worked on the class's own shared story

## When NOT to use this skill

- Generating a writing assignment itself, or a graded lesson or full unit plan (this skill produces worked prewriting examples and a classroom demonstration script, not an assignment or a full teaching cycle). A teacher asking to "teach" or "demonstrate" prewriting techniques IS in scope, since the demonstration script is a runnable classroom sequence on its own; a teacher asking for a graded assignment or a full unit plan is not.
- Producing graded student work or exemplar essays (worked examples are reference material)
- Subjects other than writing (decline gracefully and name what the skill IS for)

## What the teacher provides (conversationally, not a form)

- **Grade** (required): 1 through 8. One grade per set; the examples are calibrated tightly to it. **Grades 1-8 only.** Grammaropolis's catalog doesn't include Kindergarten or high school. If a teacher asks for either, say so plainly and decline rather than forcing a Grade 1 or Grade 8 set onto that class.
- **Source story** (optional): the class's own shared story (a field trip, the science fair, the class pet incident). If none is given, the skill uses the bundled Garvin source story (a kid cooking an anniversary dinner for a friend's parents), the worked example the Grammaropolis Writing Framework uses. A custom source story must be filled out to the schema in `reference_source_story.md`; if it is too thin, ask the teacher two or three enriching questions (sensory details, a character worth sketching, a built-in comparison) before generating.
- **Techniques** (optional): a subset of the eight. Default is all eight in standard order: Freewrite, Brainstorm, Cluster, 5W & H, Venn Diagram, Five Senses, Series of Events, Character Sketch.
- **Narrator** (optional): the default narrator is an unnamed kid the students' own age (the Grammaropolis Writing Framework's convention, and the right choice for "you can do this with your own story"). Alternatively the Mayor of Grammaropolis can narrate, using ONLY the bundled `reference_voice_card.md` and `reference_cast_card.md`; use the character option sparingly.
- **Output** (optional): worked-example set (default), or a classroom demonstration script (direct address, with stage directions for the visual techniques).

**No student data:** never ask for, store, or reason about identifiable student information. If the class source story involves real students, suggest first names only or role labels ("my lab partner"), and never collect anything beyond the story itself.

## Read before generating (all bundled in this folder)

1. `reference_source_story.md`: the Garvin source story as a structured object, the custom source-story schema, and the character-story starting points
2. `reference_grade_calibration.md`: per-grade targets for sentence length, vocabulary, and output length, with cross-check questions
3. `reference_technique_distinctiveness.md`: the eight structural signatures and the checklist that catches a freewrite that reads like a brainstorm
4. `reference_voice_card.md`: how this skill uses the characters (the Mayor as narrator), and the mechanical style rules
5. `reference_cast_card.md`: who every Grammaropolis character is, shared by all the Grammaropolis teacher skills

## Output structure

1. **The shared writing prompt**: one sentence stating what the worked examples demonstrate
2. **Framing instruction**: a short paragraph telling students the same prompt produces different content depending on technique selection, and to watch what each technique surfaces
3. **One section per technique**, in standard order, each with: the technique's definition (grade-adapted), the worked example, and one line naming the technique's distinctive signature
4. **What the spectrum demonstrates**: a three-sentence closing note on what to take from the set
5. **Standards**: one line citing W.{grade}.5 (planning), plus W.{grade}.3 when the source story is a narrative, exactly as `reference_grade_calibration.md` gives them for the grade

## The four quality checks (run before delivering)

1. **Technique distinctiveness.** Each output hits its structural signature per `reference_technique_distinctiveness.md`. If two outputs read structurally alike, rewrite until the difference is visible at a glance.
2. **Grade calibration.** Sentence length, vocabulary, and output length hit the grade's targets per `reference_grade_calibration.md`. Rewrite over-level outputs at level. **The Freewrite is the highest-risk technique for this check**: its meandering, conversational style tends to chain clauses with "and"/"but"/"so"/"because" into single long sentences that blow the grade's maximum words-per-sentence even when the total word count and sentence count look right. This is the most common failure, so do it as an explicit written step: before delivering ANY Freewrite, list each sentence with its word count next to it (e.g., "1. Twelve words. 2. Nine words. 3. Fifteen words.") as a working step in your own reasoning, never shown in the delivered set, confirm every single one is at or under the grade's maximum from `reference_grade_calibration.md`, and fix any that isn't by splitting it at its "and"/"but"/"so"/"because" into two shorter sentences, never by trimming words out of it (trimming flattens the conversational voice; splitting preserves it, see the worked contrast in `reference_technique_distinctiveness.md`). A Freewrite only passes this check once every sentence individually clears the maximum, not just the paragraph as a whole.
3. **Narrative consistency.** All outputs point to the same source story without contradiction: same narrator, same character traits, same event order, same setting, same stake.
4. **Voice integrity.** Zero em dashes and zero en dashes anywhere (use commas, colons, semicolons, parentheses, or periods); Oxford comma throughout; the kid narrator sounds age-consistent, warm, and specific; a Mayor-narrated set passes the voice card's test on every line. These rules govern the generated examples and every conversational reply too, not just this skill's files.
