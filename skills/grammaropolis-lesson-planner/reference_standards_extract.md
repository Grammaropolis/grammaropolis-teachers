# Standards extract (CCSS only)

The CCSS Language (L) and Writing (W) codes each Grammaropolis lesson teaches, grouped by topic and grade. A standard a lesson touches without teaching in full is not listed, and a plan never cites it as taught. Every code below is a code a Grammaropolis lesson teaches; do not cite a code that isn't listed here for a Grammaropolis topic, and never invent a code from memory.

**All codes are CCSS.ELA-LITERACY, prefix dropped for brevity** (e.g. `L.3.1.A` means `CCSS.ELA-LITERACY.L.3.1.A`). Codes ending in a letter (`L.3.1.A`) are sub-standards of the parent code on the same line (`L.3.1`); citing the parent is always safe, citing the sub-standard is more precise when the lesson's scope matches it exactly.

**How to use this file:** find the topic (matching `reference_topic_index.md`'s naming) and the grade, and cite the codes listed. If a teacher's topic and grade combination isn't listed, the catalog doesn't have standards coverage for that exact topic and grade; cite the nearest listed grade's codes and say so, rather than inventing a code for the missing grade.

**State standards.** This file lists Common Core codes only. Per the skill's standards-handling contract: if a teacher gives a non-CCSS state standard, resolve it to CCSS first (via the Learning Commons Knowledge Graph connector when available, or by asking the teacher for the standard's text when it isn't), then match against the codes below.
